# AI / LLM / AI Agent 学习计划

[English](README.md) | [中文](README.zh-CN.md)

A structured 3-5 month learning roadmap for AI, LLM, and AI Agent development.

Based on [Alisa Wuffles' job search blog](https://alisawuffles.github.io/blog/job-search/) — UW NLP PhD, 11 companies, 57 interviews.

## Roadmap

| Phase | Duration | Focus |
|-------|----------|-------|
| Phase 1 | 4-6 weeks | Math basics + PyTorch (30-day plan) |
| Phase 2 | 4-6 weeks | Transformer from scratch (CS336) |
| Phase 3 | 3-4 weeks | LLM deep understanding (pretrain/finetune/inference) |
| Phase 4 | 4-6 weeks | AI Agent hands-on (MCP/framework/RAG) |
| Phase 5 | Ongoing | Coding (LeetCode 75) |

## Principles

1. **No AI assistance for coding** — simulate interview conditions
2. **Code every day** — 1 hour hands-on, not just reading
3. **Take notes** — record key concepts and pitfalls daily
4. **Get it working first** — optimize later
